## 📋 소개

9년의 비즈니스 운영 경험과 기술적 역량을 결합하여 실질적인 문제를 해결하는 **Java · Spring Boot 백엔드 개발자 선하영**의 공식 포트폴리오 저장소입니다.

본 사이트는 개발자로서의 전문성과 그동안 수행해온 프로젝트 성과를 효과적으로 전달하기 위해 구축되었습니다. 단순한 이력서 이상의 깊이 있는 프로젝트 상세 내용과 기술 역량을 확인하실 수 있습니다.
